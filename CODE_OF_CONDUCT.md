# Code of conduct

Be direct, respectful, and specific.

- Discuss the work, not the person.
- Welcome questions and evidence that changes a conclusion.
- Do not harass, threaten, discriminate, or publish private information.
- Give security reporters time to coordinate a fix.
- Stop behavior that a maintainer identifies as harmful to the community.

Maintainers may edit, hide, or reject contributions that violate these rules. Serious or
repeated violations may result in removal from project spaces.
